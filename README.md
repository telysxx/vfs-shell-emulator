    # Эмулятор оболочки с виртуальной файловой системой

    Практическая работа № 1 по дисциплине «Конфигурационное управление»,
    вариант № 6. Состояние репозитория: **этап 2 из 5**.

    ## 1. Общее описание

    Консольный (CLI) эмулятор оболочки UNIX-подобной ОС на Python 3.10+
    (только стандартная библиотека).

    ## 2. Описание функций и настроек

    - параметры CLI: `--vfs`, `--prompt`, `--script`, `--config`;
- конфигурационный файл JSON (`vfs_path`, `prompt`, `startup_script`);
- приоритет: командная строка > JSON-файл > значения по умолчанию;
- шаблон приглашения: `{vfs}` и `{cwd}`;
- стартовый скрипт с комментариями `#`, ввод и вывод отображаются на экране;
- отладочный вывод всех параметров при запуске;
- команды `ls`, `cd` пока заглушки, `exit`.

    ## 3. Сборка, запуск и тесты

    ```bash
    bash run.sh        # запуск (Windows: run.bat)
    make test       # модульные тесты
    ```

    ## 4. Примеры использования

    Примеры запуска — в каталоге `scripts/os/`.
